# Contributing to wordfreq

Thanks for helping. Small, focused changes are easiest to review.

## Report a bug or ask for a feature

Open an issue with the matching template: https://github.com/example-dev/wordfreq/issues/new/choose

Include what you ran, what you expected and what happened. Paste the exact error text.

## Make a change

1. Fork the repo and create a branch from `main`.
2. Make the change. Keep the diff small and match the style of the code around it.
3. Run the tests (see "Develop" in [AGENTS.md](AGENTS.md); CI runs the same commands).
4. Add a line under `## [Unreleased]` in [CHANGELOG.md](CHANGELOG.md) for anything a user would notice.
5. Open a pull request and fill in the template.

## Ground rules

- Claims in docs need evidence in the repo (a test, an eval result or a linked source).
- Do not commit secrets, personal paths or images you may not publish.
- Be kind. This project follows the [Code of Conduct](CODE_OF_CONDUCT.md).
