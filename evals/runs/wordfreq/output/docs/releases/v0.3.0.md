# wordfreq v0.3.0

First public release of a small word frequency counter for plain text files.

## Highlights

- `wordfreq FILE... -n N --stop w1,w2` prints the most common words across one or more files.
- Case-insensitive, keeps contractions like `don't`, ignores numbers, survives invalid UTF-8.
- Python standard library only; Python 3.9+.

## Install

```sh
pip install git+https://github.com/example-dev/wordfreq@v0.3.0
wordfreq yourfile.txt -n 20
```

## Proof

- 9/10 eval cases pass (`python3 evals/run.py`, results in [evals/RESULTS.md](https://github.com/example-dev/wordfreq/blob/main/evals/RESULTS.md)).
- 3 unit tests pass in CI (`python3 -m unittest discover -v`).

## Known limitations

- ASCII letters only: `café` is counted as `caf` (the one failing eval case).
- Hyphenated words are split; no stemming; no built-in stop-word list.
- Files are read fully into memory.
- Not on PyPI; the name `wordfreq` there belongs to an unrelated project.
