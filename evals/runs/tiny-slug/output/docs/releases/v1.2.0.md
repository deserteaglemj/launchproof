# tiny-slug v1.2.0

First public release of tiny-slug, a 16-line, dependency-free Node.js function that turns any string into a lowercase ASCII URL slug.

## Highlights

- `slugify("Crème Brûlée & Café Recipes!")` returns `"creme-brulee-and-cafe-recipes"`.
- Custom separator: `{ separator: "_" }`.
- Word-safe length limit: `{ maxLength: 20 }`.
- No runtime dependencies.

## Install

```sh
npm install github:example-dev/tiny-slug
```

## Proof

Measured on 2026-10-17 with Node.js v22.23.1 ([evals/RESULTS.md](https://github.com/example-dev/tiny-slug/blob/main/evals/RESULTS.md)):

- Unit tests: 5 of 5 pass (`npm test`).
- Edge-case eval: 9 of 13 pass (`node evals/run.js`).

## Known limitations

- `maxLength` drops one word too many when the cut lands exactly on a word boundary.
- Separators containing regex characters (such as `.`) give wrong output.
- `ß`, `ø`, `ł` and similar letters become separators; non-Latin scripts give an empty string.
- CommonJS only; tested on Node.js v22 only.
