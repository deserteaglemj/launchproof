# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part (issues, pull requests, discussions) is expected to follow it.

## Reporting

Report unacceptable behavior privately to the maintainer: https://github.com/example-dev/tiny-slug/security/advisories/new. Reports are kept confidential.
