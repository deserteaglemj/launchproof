# launchproof v0.1.0

First public release of launchproof, a Claude Code and Codex plugin that turns a finished project folder into a public-ready GitHub repo and a launch plan.

## Highlights

- Full-history hygiene scan: non-noreply commit emails, personal emails, home paths, 10 secret patterns, key and `.env` files, your private names, and every image for review. Evidence is masked.
- Writes or fixes the README (hero, demo, quickstart, proof, sourced comparison, limitations, FAQ), community health files, CI with a badge, CHANGELOG, release notes, llms.txt, AGENTS.md, a Pages landing page with JSON-LD and Open Graph, robots.txt, sitemap, topics and a social preview.
- `lp.py audit`: a 0 to 100 launch checklist the agent loops on until it scores 90 or more.
- Launch plan with dated steps and drafts for Show HN, Reddit, X, LinkedIn, Product Hunt, Dev.to, Discord, awesome lists, plugin directories and newsletters.
- Never pushes, publishes or posts; returns the commands for you to approve.

## Install

```bash
claude plugin marketplace add deserteaglemj/launchproof
claude plugin install launchproof@launchproof
```

Codex: `codex plugin marketplace add deserteaglemj/launchproof`, then `codex plugin add launchproof@launchproof`.

## Proof

3 eval cases, 2 pass ([evals/RESULTS.md](https://github.com/deserteaglemj/launchproof/blob/main/evals/RESULTS.md)): wordfreq 18.5 to 97.2 (100.0 after the owner-approved rewrite), tiny-slug 11.1 to 97.2 (100.0 final), shotproof 77.8 to 97.2 (fails: a private name in its public history needs an owner rewrite). The agent never pushed, added a remote or rewrote history.

## Known limitations

- The audit checks structure and evidence links, not writing quality.
- 10 secret patterns; install gitleaks for wider coverage.
- 3 eval cases, one run each.
